### What I'm building

| | |
|---|---|
| **[CodeArena](https://github.com/Dharaneswara-Reddy/CodeArena)** | A full online judge on Go, Gin, React and MongoDB. Sandboxed execution with no network and hard resource caps, a RabbitMQ judging pipeline, real-time 1v1 races over WebSockets, and an AI tutor engineered never to hand over the answer. 632 Go tests. |
| **[Constitutional AI](https://github.com/Dharaneswara-Reddy/Constitutional-AI-Alignment-Without-Humans-in-the-Loop-)** | Anthropic's Constitutional AI implemented end to end on an 8GB consumer GPU — a 1.5B Qwen2 model aligned with GRPO and QLoRA, judged by written principles instead of human preference labels. |
| **[AI Ops Copilot](https://github.com/Dharaneswara-Reddy/Multi_Agent_RAG_System_For_Enterprise_Log_And_Knowledge_Search)** | Multi-agent RAG over logs and documentation. Hybrid BM25 + dense retrieval with cross-encoder re-ranking, scored against a hand-built 95-case golden set: recall@k 0.979. |
| **[Churn ML System](https://github.com/Dharaneswara-Reddy/Churn_ML_System)** | The full lifecycle: model selection on PR-AUC with bootstrap confidence intervals, Brier calibration, SHAP explanations, PSI drift detection and automated retraining behind a FastAPI service. |
| **[durexec](https://github.com/Dharaneswara-Reddy/durexec)** | A fault-tolerant, horizontally sharded durable execution engine in Go. Event-sourced log written before every action, lease-based sharding with fencing tokens, saga compensation. 378 tests. |
| **[SecretGuard](https://marketplace.visualstudio.com/items?itemName=secretguard.secretguard-git-protect)** | A published VS Code extension that stops API keys reaching git history — live detection, a pre-commit blocker and a 500-commit history audit. |
